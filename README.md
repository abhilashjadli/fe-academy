# FE Library

A library of standalone explorable chapters on financial engineering, for engineers joining a financial engineering firm.

- `docs/charter.md` — the locked project charter (what, for whom, syllabus, process). Read first.
- `research/` — illustration research: `illustration-catalogue.md` (synthesis), `3b1b/` (3Blue1Brown animation-code catalogue by year), `sites/` (explorable-explanation site audits), `<chapter-id>.md` (per-chapter research notes + storyboards).
- `reviews/` — independent reviews (Antigravity / Gemini) per chapter.
- `apps/web/` — the site (not started yet).
