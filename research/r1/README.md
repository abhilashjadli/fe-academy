# Phase R1 deep research notes (sprint of 2026-10-22)

One file per chapter, written for a **discussion with the sponsor** — options, not decisions. The sponsor's brief for this sprint:

> The consumers are freshers (engineers, not financial engineers yet). The content must be easy to understand, elicit real interest in continuing, and not look like rocket science. Illustrations don't only need to be interactive — they need to be easy. Vary the illustration style per topic; sliders are one mode among many. Research, research, research.

## Required template for `research/r1/<ID>.md`

```
# <ID> <title>

## 1. What a fresher must walk away feeling (one sentence, plain words — no symbols)
## 2. Why a fresher should care (the hook candidates — 3, each one paragraph: a puzzle, a story with stakes, an everyday object; which is strongest and why)
## 3. The sources, actually reopened
   - Book chapters read (book, chapter, pages) and what each does well / badly for a beginner
   - 3Blue1Brown scenes re-read (file paths) and the exact visual move that is reusable
   - Best beginner explanations found on the web (URL, who, the analogy or visual they use, why it works) — at least 5, found by search, not from memory
   - Common misconceptions (from forums, StackExchange, textbooks' own warnings)
## 4. Three illustration concepts, in three DIFFERENT modes
   For each: the mode (see research/style/modes.md once written; meanwhile name it plainly: icon grid, drawn-character story, symbol-into-picture derivation, physical simulation, game, guess-then-reveal, comic strip, annotated real artefact, scrubbable animation, explorable, step-through, clip, illustrated text…), a 5–8 beat storyboard, what it makes visible that text cannot, what it costs to build, the risk that it confuses a fresher
## 5. My recommendation (one concept, or a sequence of two) and why — judged by: easy to understand first, interesting second, interactive third
## 6. Mathematics the chapter must get right (formulas, assumptions) and reference numbers for tests, with their source (book + page)
## 7. Where it connects (previous/next chapters, and the one real-world moment a fresher will meet it)
## 8. Open questions for the sponsor
```

Length: 1,500–3,000 words per chapter. Prefer concrete over generic. Quote the sources' own words where they are good. Never invent a URL; mark anything not actually opened as "(not opened)".
